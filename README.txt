ADAMS SCHEMA – GitHub Pages
1. Skapa ett public repository: adam-schema, med README.
2. Ladda upp alla 8 appfiler i rotmappen. Ladda inte upp ZIP-filen.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Öppna webbadressen som GitHub visar när publiceringen är färdig.
5. På iPhone: öppna i Safari, Dela → Lägg till på hemskärmen.

Avbockningar sparas i localStorage per datum. Historik och streaks finns kvar över veckor. Exportera säkerhetskopior regelbundet. Samma enhet och webbadress behövs. Ingen molnsynkning eller konto ingår. Webbplatsdata kan raderas av användaren eller webbläsaren. Offlineläget aktiveras efter första onlinebesöket. Appen använder svensk tid.

GitHub Pages och appens schema är offentliga. Avbockningar och exporterade säkerhetskopior laddas inte upp. Publicera aldrig backup-filen på GitHub.

Sömnen bekräftas separat och gäller natten som slutade den valda morgonen. Tränings- och dagliga mål följer ditt schema. Sov-raden bekräftar läggning, inte åtta timmars sömn.
